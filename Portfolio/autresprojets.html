SÉCURISATION D'UN SITE AVEC OWASP

Apprendre à protéger une application web dès ses premières lignes de code, selon les principes de l'OWASP.

Apprendre à protéger une application web dès ses premières lignes de code, c'était l'objectif de ce projet de sécurisation en PHP, réalisé selon les principes de l'OWASP.

Pour les moins expérimentés : il s'agit ici d'une requête préparée, une technique qui permet de se prémunir contre les injections SQL, l'une des failles les plus connues et exploitées sur le web.

L'idée est simple : au lieu qu'un utilisateur mal intentionné puisse renseigner du code dans un formulaire, ici le système ne peut jamais interpréter ce que l'utilisateur saisit comme du code.

Les plus expérimentés auront remarqué l'usage de SHA-256 pour le hachage du mot de passe. Cette méthode est aujourd'hui à éviter en production — ce choix a été fait dans un cadre pédagogique.

En approfondissant mes connaissances, j'ai découvert qu'il est préférable d'utiliser password_hash() et password_verify() en PHP, qui incluent automatiquement un sel cryptographique.

TESTS UNITAIRES EN JAVA

Mettre en place des tests unitaires avec JUnit, afin de valider le bon fonctionnement d'une calculatrice codée en Java.

Dans ce projet, l'objectif était de mettre en place des tests unitaires avec JUnit, afin de valider le bon fonctionnement d'une calculatrice codée en Java.

Chaque opération (addition, soustraction, multiplication, division) a été testée avec différents cas : valeurs positives, négatives, et même la division par zéro.

Ce que montre l'extrait ci-dessus : la structure typique d'un test unitaire. On prépare l'environnement, on appelle la méthode à tester, puis on vérifie le résultat avec assertEquals().

Ces tests permettent de détecter automatiquement toute anomalie. C'est une bonne pratique essentielle dans les projets de développement professionnels.

SERVEUR DNS

Déployer un environnement serveur complet via Windows Server 2016 dans une machine virtuelle, avec les rôles AD DS et DNS.

Ce projet avait pour objectif de déployer un environnement serveur complet via Windows Server 2016 dans une machine virtuelle, en installant les rôles AD DS et DNS.

Windows Server 2016 a été choisi pour sa stabilité et sa compatibilité avec les fonctionnalités avancées comme Active Directory. Une fois le rôle AD installé, le serveur DNS est automatiquement configuré.

Le tableau de bord confirme que les rôles ont été correctement installés et sont opérationnels.

Un test DNS a été réalisé à l'aide de la commande nslookup. Le serveur répond bien, preuve que le DNS est fonctionnel.

La commande netdom query fsmo montre que le serveur occupe tous les rôles FSMO, confirmant qu'il est bien contrôleur de domaine principal.

Ce projet m'a permis de mieux comprendre les bases du réseau d'entreprise, la gestion des domaines via Active Directory, et le fonctionnement interne du DNS dans un environnement Windows Server.

GPO

Une GPO (Group Policy Object) permet aux administrateurs système de déployer et appliquer des stratégies sur les ordinateurs d'un domaine Active Directory.

Une GPO (Group Policy Object) est un outil essentiel permettant aux administrateurs système de déployer et appliquer des stratégies sur les ordinateurs et les utilisateurs d'un domaine Active Directory. Elle facilite l'automatisation de configurations et l'application de règles sur l'ensemble du réseau.

Les GPO permettent de gérer divers aspects des postes de travail : paramètres réseau, restrictions d'accès, et exécution automatique de scripts. Elles sont couramment utilisées pour améliorer la sécurité et optimiser la gestion informatique.

Dans mon projet, j'ai mis en place une GPO visant à afficher une image de présentation lors de l'ouverture des sessions utilisateurs :

  • Création d'une nouvelle GPO via la console de gestion des stratégies de groupe.
  • Ajout d'un script PowerShell dans la GPO pour ouvrir l'image dans un navigateur.
  • Définition de la GPO pour exécuter le script à l'ouverture de la session.
  • Application de la GPO aux utilisateurs concernés et vérification du bon fonctionnement.
